🗺️ Exam Blueprint

Know What You're Fighting For

GH-600 covers 6 domains. Know the weights. Know the key topics. Build something in each one. That's the formula. 😤

1
🏗️ Prepare Agent Architecture & SDLC Processes
15–20%
  • Define agent goals, roles, and operational boundaries
  • Decompose complex tasks into agent-executable sub-tasks
  • Choose the right models, tools, and data sources
  • Design SDLC workflows with agents at the right touchpoints
  • Version prompts, tools, and configurations like code
Projects README / ADRs CODEOWNERS Milestones
2
🔧 Implement Tool Use & Environment Interaction
20–25%
  • Design and implement tool schemas (JSON Schema — be precise)
  • Enable safe tool execution: sandboxing, validation, sanitization
  • Integrate with APIs, databases, CLIs, and file systems
  • Manage secrets securely — never hardcode, always rotate
  • Handle side effects and ensure idempotency
Actions Secrets & Variables Environments Packages
3
🧠 Manage Memory, State & Execution
10–15%
  • Choose episodic, semantic, or hybrid memory strategies
  • Persist and retrieve state reliably across agent runs
  • Manage context windows — trim, summarize, compress
  • Enable checkpoints and resumption for long-running tasks
  • Ensure determinism to avoid flaky agent behavior
Artifacts Cache Releases Discussions
4
📊 Perform Evaluation, Error Analysis & Tuning
15–20%
  • Build evaluation datasets and test harnesses for agents
  • Define metrics: quality, safety, latency, and cost
  • Run automated evals in CI/CD — every PR, every deploy
  • Analyze errors and failure modes systematically
  • Tune prompts, tools, and models iteratively
Actions (CI) Code Scanning Pages Pull Requests
5
🕸️ Orchestrate Multi-Agent Coordination
15–20%
  • Design agent roles, contracts, and interaction protocols
  • Coordinate via workflows and events — not spaghetti
  • Master patterns: plan, debate, delegate, critique
  • Resolve conflicts and aggregate results across agents
  • Monitor and trace multi-agent behavior end-to-end
Actions (Workflows) Webhooks Artifacts Projects
6
🛡️ Implement Guardrails & Accountability
10–15%
  • Implement content safety and policy guardrails
  • Enforce least privilege — agents only get what they need
  • Add human-in-the-loop for high-risk or irreversible actions
  • Audit, log, and trace every decision an agent makes
  • Ensure compliance with data governance requirements
CODEOWNERS Branch Protection Audit Log Dependabot

🎯 Hands-On Build Checklist

For each domain, build one real artifact. This is the hands-on equivalent of the study guide objectives.

  • D1 Write an agent spec (YAML) for a code review agent. Include goals, tool access list, and operational boundaries.
  • D2 Implement a tool with a valid JSON Schema definition. Call it from a GitHub Action using environment secrets.
  • D3 Build a simple state persistence mechanism using GitHub Artifacts and Cache across workflow runs.
  • D4 Create an eval harness for a Copilot extension. Define at least 3 metrics (quality, safety, latency) with threshold assertions.
  • D5 Design a 2-agent orchestration flow using GitHub Actions workflows and webhooks. Document the communication contracts.
  • D6 Add a content safety guardrail and a human approval gate (environment protection rule) to a GitHub Actions workflow.
