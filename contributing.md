# Contributing

Thank you for taking the time to contribute! 🙌

## Guidelines

- **Quality over quantity.** Only suggest resources that are genuinely useful and directly relevant to GH-600 exam domains or agentic AI development with GitHub Copilot.
- **No duplicate links.** Search the list before submitting.
- **No paywalled resources** without a clear note that a paywall exists.
- **No AI-generated fluff.** Low-quality, auto-generated content will be rejected.
- **No unmaintained or deprecated resources.** If a repo is archived or a link is broken, open a PR to remove it.

## How to Contribute

1. Fork this repository.
2. Make your changes in a new branch.
3. Add your resource to the appropriate section. Follow the existing format: `- [Name](URL) - Short, objective description ending with a period.`
4. Ensure the description is objective (not a tagline or marketing blurb) and starts with an uppercase letter.
5. Open a Pull Request with a clear title and brief explanation of why the resource belongs here.

## Formatting Rules

- Descriptions start with an uppercase character and end with a period.
- Links and descriptions are separated by a dash: `- [Name](URL) - Description.`
- Entries go at the bottom of the appropriate section.

## What Qualifies

- Official Microsoft Learn / GitHub Copilot documentation and modules
- Community tutorials, blog posts, or videos with demonstrable technical depth on GH-600 domains
- Tools, templates, or repos that directly support building, evaluating, or governing AI agents on GitHub
- Community discussions or threads with substantive exam prep value

## What Does Not Qualify

- Generic AI content not specific to agentic workflows or GitHub Copilot
- Marketing pages or vendor landing pages
- Broken or redirecting links
- Content that duplicates what is already linked
